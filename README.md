## 📦 Project Setup

Clone & Run Locally:
```bash
git clone https://github.com/NallamalaAkshay/akshaynallamala.git
cd akshaynallamala
npm install
npm run dev
```

Production Build:
```bash
npm run build
npm run preview
```
